AWS CloudWatch Agent Setup Guide

📘 Overview

Amazon CloudWatch Agent helps you collect system-level metrics and logs (CPU, memory, disk, and custom logs) from your Amazon EC2 instances or on-premises servers. This guide explains how to install, configure, and manage the CloudWatch Agent step by step.

⚙️ Prerequisites

  • An AWS account
  • IAM Role or IAM User with CloudWatchAgentServerPolicy attached
  • Amazon EC2 instance (Linux/Windows) or on-premises server
  • Basic knowledge of Linux/Windows commands

📥 Installation

# For Amazon Linux / RHEL
sudo yum install amazon-cloudwatch-agent

# For Ubuntu / Debian
sudo apt-get install amazon-cloudwatch-agent

🛠️ Configure the CloudWatch Agent

Use the CloudWatch Agent configuration wizard to generate a config file: 

sudo /opt/aws/amazon-cloudwatch-agent/bin/amazon-cloudwatch-agent-config-wizard

▶️ Start the CloudWatch Agent

sudo /opt/aws/amazon-cloudwatch-agent/bin/amazon-cloudwatch-agent-ctl \
    -a fetch-config \
    -m ec2 \
    -c file:/opt/aws/amazon-cloudwatch-agent/etc/amazon-cloudwatch-agent.json \
    -s

🔍 Check the status of the Agent

sudo /opt/aws/amazon-cloudwatch-agent/bin/amazon-cloudwatch-agent-ctl -a status

✍️ Manually create or edit the CloudWatch config file

The CloudWatch Agent uses a JSON configuration file. You can manually edit it to customize metrics and logs.

📂 Path to Config File

/opt/aws/amazon-cloudwatch-agent/etc/amazon-cloudwatch-agent.json

🔑 Change File Permissions

sudo chown root:root /opt/aws/amazon-cloudwatch-agent/etc/amazon-cloudwatch-agent.json
sudo chmod 644 /opt/aws/amazon-cloudwatch-agent/etc/amazon-cloudwatch-agent.json

📝 Example Config File

{
  "agent": {
    "metrics_collection_interval": 60,
    "run_as_user": "root"
  },
  "metrics": {
    "metrics_collected": {
      "cpu": {
        "measurement": ["usage_system", "usage_user"]
      },
      "mem": {
        "measurement": ["mem_used_percent"]
      },
      "disk": {
        "measurement": ["used_percent"],
        "resources": ["*"]
      }
    }
  }
}
