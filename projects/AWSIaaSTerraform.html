Architecture Details

Designed a modular Terraform codebase following DRY (Don't Repeat Yourself) principles with separate environments (development, staging, production) managed via Terraform workspaces and remote state locking in S3 + DynamoDB.

  • Networking & Isolation: 3-tier VPC architecture across 2 Availability Zones containing Public, Private Application, and Isolated Database subnets with route table controls.
  • Compute Services: Containerized workloads on AWS ECS Fargate, eliminating server patching and scaling based on CPU/Memory thresholds.
  • Security & Ingress: AWS WAF protecting API Gateway with rate limiting, SQL injection rules, and JWT verification before routing to backend microservices.
  • CI/CD Pipeline: AWS CodePipeline and CodeBuild triggering automatic Docker build and deployment upon git push, complete with CloudWatch alarms and SNS notification topics.
