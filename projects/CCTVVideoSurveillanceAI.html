Engineering Architecture & Contributions

1. Custom YOLO Model Fine-Tuning & False-Positive Suppression

Trained and tuned custom YOLO object detection models across 10,000+ curated and annotated images (using CVAT & Label Studio). Optimized detection for persons, staff/visitor status, PPE wear, carried items, and facility physical state. Designed targeted augmentations (contrast jitter, shadow simulation, glare filtering) to tackle difficult real-world CCTV lighting conditions, elevating detection precision from ~82% to ~91% mAP@0.5.

2. Hardware-Accelerated Video Pipeline & Edge Inference

Built an ultra-low latency RTSP ingestion pipeline using GStreamer with NVIDIA hardware codecs (nvv4l2decoder and nvv4l2h264enc). Deployed TensorRT-optimized models directly onto NVIDIA Jetson Orin Nano Super edge appliances, sustaining smooth 35–45 FPS multi-stream processing 24/7 without frame drop, and scaling up to 100+ FPS on a dual-GPU local rig (2× RTX 5090).

3. Identity Vector Search with ArcFace & PostgreSQL pgvector

Replaced brittle face-matching heuristics with InsightFace/ArcFace high-dimensional (512-D) facial embedding extraction. Indexed facial vectors into PostgreSQL using pgvector with HNSW (Hierarchical Navigable Small World) indexing, delivering sub-15ms nearest-neighbor identity lookups across large employee databases.

4. Containerized SageMaker Deployment & MLOps Automation

Architected custom Docker containers for real-time inference on AWS SageMaker (ml.g5.xlarge / ml.g5.2xlarge). Integrated the deployment lifecycle with AWS CodePipeline, ECR, and CloudWatch alarms for automated blue/green canary promotions and automated endpoint health recovery.

5. Multimodal LLM Summaries & Cloud Security Hardening

Integrated foundation LLMs to generate continuous natural-language surveillance event logs, enabling operators to query surveillance history via semantic RAG search ("show unescorted visitors near server room after 8 PM"). Implemented VPC endpoints, WAF rules, GuardDuty anomaly detection, and AWS Inspector security scanning, achieving an 80% cloud security benchmark score with HIPAA & SOC 2 compliance.
